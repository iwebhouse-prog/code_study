# TASK-033. 로그인 폼 (LoginForm)

## 상태
완료

## 날짜
2026-11-09

## 작업 요약
로그인 화면의 **입력 양식**을 만들었습니다. 이메일 칸, 비밀번호 칸, "로그인" 버튼으로 이루어져 있고, 누르는 동안은 "로그인 중…"으로 바뀌며 잠깁니다. 아파트 출입구의 인터폰과 비슷합니다. 호수와 비밀번호를 누르면 잠시 "확인 중"이라고 뜨고, 틀리면 이유가 나옵니다.

회원가입 양식과 다른 점은 비밀번호 규칙입니다. 로그인할 때는 **칸이 비어 있는지만** 봅니다. 가입 때의 규칙(8자 이상 등)을 로그인에서도 검사하면, 규칙이 바뀌기 전에 가입한 사람이 "비밀번호 형식이 틀렸습니다"라는 엉뚱한 안내를 받을 수 있기 때문입니다. 맞는지 틀린지는 서버가 정합니다.

## 왜 이렇게 만들었나
- **정답은 서버만 압니다.** 우리가 화면에서 할 일은 빈칸 확인까지이고, 비밀번호가 맞는지는 서버가 `invalid_credentials` 같은 답으로 알려 줍니다. 그 문장을 경고 상자에 그대로 보여 줍니다.
- **가입 양식과 뼈대를 나눠 씁니다.** 칸, 오류 표시, 버튼 잠금은 공통 부품(`CredentialsForm`)이 맡고, 로그인 파일은 라벨과 규칙만 정해 줍니다.
- **예상 못 한 오류도 처리합니다.** 서버가 아닌 곳에서 난 오류라면 "문제가 발생했습니다. 잠시 후 다시 시도하세요."라고 안내합니다.

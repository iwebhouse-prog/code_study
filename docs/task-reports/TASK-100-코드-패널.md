## 작업 요약
학습 문서 화면 왼쪽에 **업로드한 코드를 읽기 전용으로 보여 주는 패널**입니다. 안쪽 에디터는 T099의 Monaco 껍데기를 씁니다.

- 파일이 하나면 파일 경로만 위에 보여 주고, 여러 개면 파일 탭을 보여 줍니다(탭 이름은 파일 경로).
- 파일 언어(`python`, `cpp`, `text` …)를 Monaco 언어 이름으로 바꿉니다. 모르는 언어와 `text`는 `plaintext`입니다.
- `highlight`(파일 경로 + 시작·끝 줄)를 받으면 그 줄을 칠하고 화면 안으로 스크롤합니다. 다른 파일을 가리키면 그 파일 탭으로 먼저 옮깁니다.
- 사용자가 스크롤하면 `onTopLineChange(파일경로, 맨 위 줄)`로 알립니다.
- 코드가 없으면 "표시할 코드 파일이 없습니다."를 보여 줍니다.

"특정 줄로 스크롤"은 강조 범위를 주면 함께 일어나므로 별도 속성을 만들지 않았습니다(시험이 요구하지 않는 기능은 넣지 않는 원칙).

## 기술 결정
- 시험에서는 `LazyCodeEditor`를 가짜로 바꿔 에디터가 받은 속성만 확인합니다.
- 다른 파일로 강조가 옮겨 가는 동작은 렌더링 중 상태 보정 방식(`useState`로 이전 값 기억)으로 구현했습니다. `useEffect`로 하면 한 번 더 깜빡이며 그려지기 때문입니다.
- 파일 탭은 기존 `Tabs` 부품을 재사용했습니다.

## 관련 개념
- **읽기 전용 에디터**: 보기와 선택만 되고 고칠 수 없는 편집기.
- **제어되는 컴포넌트**: 어떤 줄을 강조할지는 부모(DocumentViewer)가 정합니다.

## 주의할 점 (비고)
- 실제 Monaco 동작(색칠, 스크롤 알림)은 jsdom에서 시험할 수 없어 브라우저 시험에서 확인해야 합니다.
- 같은 경로의 파일이 둘이면 탭이 겹치지만, 업로드 규칙상 경로는 유일합니다.

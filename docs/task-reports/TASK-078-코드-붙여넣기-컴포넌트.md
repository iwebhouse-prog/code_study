# TASK-078. 코드 붙여넣기 컴포넌트 (PasteCode)

## 상태
완료

## 날짜
2026-11-16

## 작업 요약
파일이 없어도 코드를 바로 붙여 넣어 올릴 수 있게 하는 컴포넌트입니다. **메모장과 이름표**를 생각하면 됩니다. 메모장(글상자)에 코드를 쓰고, 이름표(언어 선택)에 "이 글은 Python입니다"라고 적어 함께 보냅니다.

1. "붙여넣을 코드" 글상자(고정폭 글꼴).
2. "프로그래밍 언어" 선택 상자. 첫 항목은 "언어 선택"이고 필수 입력입니다.
3. 언어 항목은 계약서의 한국어 이름입니다: Python, JavaScript, TypeScript, HTML, CSS, Java, C, C++, Markdown, 일반 텍스트.
4. 서버가 기대하는 값(`python`, `cpp`, `text` 등)을 부모에게 전달합니다.
5. 서버나 모달의 오류 문구를 각 입력 옆에 보여 줄 수 있습니다(`codeError`, `languageError`).

## 기술 결정
- 화면용 선택 상자는 새 라이브러리 없이 기본 `<select>`를 사용했습니다. 키보드와 모바일에서 가장 안정적입니다.
- 언어 목록은 백엔드의 `SUPPORTED_LANGUAGES`와 같은 10개입니다.

## 관련 개념
- **제어 컴포넌트**: 입력값을 컴포넌트가 아니라 부모가 들고 있고, 바뀔 때마다 알려 주는 방식입니다. 모달이 제출 시점에 값을 모으기 쉽습니다.
- **`aria-describedby`**: 오류 문구를 입력과 연결해 스크린 리더가 함께 읽게 합니다.

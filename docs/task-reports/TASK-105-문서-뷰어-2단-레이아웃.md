## 상태
완료

## 날짜

## 작업 요약
학습 문서가 완성되면 **왼쪽 코드, 오른쪽 설명** 두 칸으로 보여 주고 둘을 줄 번호로 이어 주는 화면입니다.

- 넓은 화면(`lg`)에서는 두 칸, 좁은 화면에서는 위아래로 쌓입니다.
- 설명 항목(4장)을 누르면 그 항목의 파일 탭으로 옮겨 해당 줄을 강조하고 스크롤합니다.
- 코드를 스크롤하면 맨 위에 보이는 줄을 포함하는 4장 항목이 활성화되고, 설명 패널이 그 항목으로 스크롤합니다. 어느 항목에도 속하지 않는 줄이면 현재 항목을 유지합니다. 스크롤만으로는 코드 강조를 바꾸지 않습니다.
- 코드는 `GET /tasks/{id}/code`로 받습니다(기존 `taskService.getCode`). 코드 요청이 실패해도 설명은 계속 보여 주고 코드 칸에만 오류를 표시합니다.
- 문서를 받는 동안에는 "학습 문서를 불러오는 중입니다…", 실패하면 오류 알림을 보여 줍니다.

## 기술 결정
- 줄 → 항목 찾기는 같은 파일 경로이면서 `시작 ≤ 줄 ≤ 끝`인 첫 항목입니다.
- 항목 클릭으로 코드를 움직일 때 생기는 스크롤 이벤트는 Monaco 래퍼(T099)가 "프로그램 스크롤"로 걸러 되먹임을 막습니다.

## 관련 개념
- **동기화 스크롤**: 한쪽 스크롤에 맞춰 다른 쪽이 따라가는 UI.
- **반응형 그리드**: 화면 너비에 따라 칸 수가 바뀌는 레이아웃.

## 주의할 점 (비고)
- 되먹임 방지(프로그램 스크롤 구분)는 jsdom에서 시험할 수 없어 브라우저 시험(T112)에서 확인해야 합니다. Monaco가 `Immediate` 스크롤 이벤트를 동기로 보낸다는 가정에 기대고 있습니다.
- 줄 범위가 겹치는 항목은 먼저 나온 항목이 선택됩니다.

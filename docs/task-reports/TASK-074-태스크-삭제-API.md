# TASK-074. 태스크 삭제 API (DELETE /tasks/{task_id})

## 상태
완료

## 날짜
2026-11-16

## 작업 요약
태스크를 **휴지통으로 보내는** API입니다. 책상 위 서류를 바로 파쇄하지 않고 "휴지통 서랍"에 넣어 두었다가 30일 뒤 정리하는 방식입니다(`SoftDeleteMixin`).

- `204`(본문 없음): 태스크가 휴지통으로 이동하고 `trashed_at`, `scheduled_deletion_at`(30일 뒤)이 기록됩니다.
- 이후 조회·수정·코드 조회·목록에서 사라지고 `404`가 됩니다. 같은 태스크를 다시 지우려 해도 `404`입니다.
- 업로드된 **파일은 디스크에 그대로** 둡니다(영구 삭제 때까지).
- 태스크 번호는 재사용되지 않습니다. 삭제 뒤 새로 만들면 다음 번호를 받습니다.
- 프로젝트의 `last_activity_at`이 갱신되고, 프로젝트의 `task_count`가 줄어듭니다.
- `403`(남의 태스크), `404`, `400`(UUID 아님), `401`

## 기술 결정
- 소프트 삭제(휴지통)이므로 `DELETE` 문이 아니라 `move_to_trash()`만 호출합니다. 복원 기능(US 휴지통)은 나중에 같은 필드를 되돌리면 됩니다.
- 번호 재사용 방지는 모델의 `next_number_query`(휴지통 포함 최대값 + 1)가 이미 보장합니다. 이 API 시험이 그 약속을 끝에서 끝까지 확인합니다.

## 관련 개념
- **소프트 삭제**: 행을 지우지 않고 "삭제됨" 표시만 하는 방식입니다. 실수로 지워도 되살릴 수 있습니다.
- **204 No Content**: 성공했지만 돌려줄 내용이 없다는 응답입니다.

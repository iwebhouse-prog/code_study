## 작업 요약
카드의 제목을 눌렀을 때 열리는 **프로젝트 한 건의 화면**을 만들었습니다. 이름표만 붙어 있던 서랍을 열어 안의 내용물(제목, 설명, 만든 날짜, 마지막 활동, 완료 태스크 수)을 보여 주고, 이름표를 고치거나 서랍을 휴지통에 넣는 버튼도 달았습니다.

- 태스크 자리: "태스크 목록은 곧 제공됩니다." 안내 (나중에 목록이 들어올 빈 칸)
- **수정**: 생성 창을 재사용해 현재 값이 채워진 상태로 열림. 바뀐 항목만 서버에 보냄. 설명을 비우면 지우기 요청(null). 아무것도 안 바꾸면 서버에 묻지 않고 닫기. 성공하면 "프로젝트가 수정되었습니다." 알림
- **삭제**: 화면 안의 확인 창("프로젝트를 삭제할까요?"). 브라우저 기본 확인창은 쓰지 않음. 확인하면 "프로젝트가 휴지통으로 이동되었습니다." 알림 후 대시보드로 이동
- 권한 없음(403)이나 없는 프로젝트(404): 서버가 준 문구와 "내 프로젝트로 돌아가기" 링크

## 왜 이렇게 만들었나
- 수동 시험 T059(수정), T060(삭제)이 이 화면에서 이루어지므로 수정과 삭제를 함께 넣었습니다.
- 삭제 확인 창은 `alertdialog`(경고 대화상자)로 열어 화면 읽기 도구가 "중요한 확인"임을 알리게 했습니다. 실패하면 창 안에 이유가 나오고 창은 닫히지 않습니다.
- 삭제 성공 후에는 이동을 먼저 하고 그 프로젝트의 캐시를 지웠습니다. 순서가 반대이면 이미 지워진 프로젝트를 다시 불러 "찾을 수 없음" 오류가 잠깐 깜빡일 수 있습니다.

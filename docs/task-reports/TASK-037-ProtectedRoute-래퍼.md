## 상태
완료

## 날짜

## 작업 요약
로그인한 사람만 들어갈 수 있는 화면들(대시보드, 프로젝트, 태스크, 휴지통) 앞에 **화면 쪽 문지기**를 세웠습니다. 문지기는 로그인 상태를 세 가지로 구분해서 다르게 행동합니다.

- **아직 모름**(앱을 막 열어 서버에 물어보는 중): "로그인 상태를 확인하는 중입니다…"를 보여 주고 기다립니다. 이동시키지 않습니다.
- **로그인 안 함**: 로그인 페이지로 보내면서 "원래 가려던 주소"를 쪽지로 건넵니다.
- **로그인함**: 그대로 통과시킵니다.

회사 로비 경비원을 떠올리면 됩니다. 신원 확인 중인 방문객을 "나가세요"라고 내쫓지 않고 잠깐 대기시키는 것이 핵심입니다. 그렇지 않으면 로그인한 사람도 새로고침할 때마다 로그인 화면을 한 번씩 보게 됩니다.

## 왜 이렇게 만들었나
- **"모름"을 따로 둔 이유**는 T021 저장소 설계 때부터 정해 둔 약속입니다.
- **라우트 묶음 전체에 한 번만 씌웁니다.** 화면마다 검사 코드를 넣으면 하나를 빠뜨리기 쉽습니다. `routes.tsx`의 "로그인 후 화면 그룹"에 문지기를 한 번 달았습니다.
- **로그인 상태가 중간에 풀려도 반응합니다.** 세션이 끝나면 저장소가 "로그인 안 함"으로 바뀌고, 문지기가 그 변화를 보고 자동으로 로그인 페이지로 보냅니다.

## 변경 파일

- `frontend/src/routes.tsx` (로그인 후 화면 그룹에 문지기 연결)

- `frontend/tests/setup.ts` (모든 시험의 시작 상태를 "로그인함"으로)

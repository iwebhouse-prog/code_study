## 작업 요약
회원 전용 구역 입구에 세울 **문지기**를 만들었습니다. 앞으로 만들 API 주소에 `user: CurrentUser` 한 줄만 적으면, 이 문지기가 요청마다 입장권을 확인합니다. 통과하면 "이 손님이 누구인지"를 주소 처리 코드에 넘겨줍니다.

문지기가 하는 일은 네 단계입니다.

1. 쿠키에 입장권(액세스 토큰)이 있는지 봅니다. 없으면 "로그인이 필요합니다"라고 답합니다.
2. 입장권이 진짜인지, 기간이 남았는지 봅니다(T026).
3. 회원 대장에서 그 사람을 찾습니다.
4. 찾으면 들여보내고, 없으면 세션이 만료되었다고 답합니다.

아직 실제로 보호되는 주소는 없습니다. 실제 사용은 T029A부터입니다.

## 왜 이렇게 만들었나
- **입장권이 진짜여도 회원 대장을 한 번 더 봅니다.** 입장권은 발급 후 15분간 스스로 유효해서, 탈퇴한 사람이 들고 있어도 진짜로 보입니다. 대장을 확인해야 막을 수 있습니다.
- **쿠키만 받습니다.** 입장권을 자바스크립트가 못 읽는 쿠키에 두기로 정했으므로(research.md 8장), 다른 경로를 열어 둘 이유가 없습니다.
- **대장 조회는 창구 직원에게 맡깁니다.** 프로젝트 규칙(주소 → 서비스 → 모델)에 따라 문지기가 직접 대장을 뒤지지 않고 `UserService.get_by_id()`를 부릅니다.
- **답을 나누어 줍니다.** 기간이 지났으면 `token_expired`로 답해 화면이 조용히 새 입장권을 받게 하고, 쿠키가 없으면 `unauthorized`, 가짜면 `session_expired`로 답합니다.

# TASK-079. 태스크 카드 (TaskCard)

## 상태
완료

## 날짜
2026-11-16

## 작업 요약
프로젝트 화면의 태스크 목록에서 태스크 하나를 보여 주는 **명함**입니다. 이름(제목), 번호, 만든 날, 주요 특징(언어)만 간단히 적고, 누르면 상세 화면으로 이동합니다.

카드에 나오는 것(계약서의 "Task cards" 규칙):
1. "Task 1"처럼 번호
2. 제목(링크, `/tasks/{id}`로 이동)
3. "만든 날짜: 2026년 11월 16일"
4. 언어 이름(예: JavaScript, 일반 텍스트). 아직 분석 전이면(`null`) "분석 중"

기존 프로젝트 카드(ProjectCard)와 같은 `Card` 부품을 써서 모양을 맞췄습니다.

## TDD 결과

- **이 작업에서 기존 테스트 파일은 고치지 않았습니다.**

## 기술 결정
- 카드 제목은 `h3`로 했습니다. 프로젝트 화면의 "태스크" 구역 제목이 `h2`이므로 한 단계 아래입니다(제목 계층을 지킴).
- 복잡도(초급/중급)는 계약서가 카드에 요구하지 않아 표시하지 않았습니다.

## 관련 개념
- **재사용 컴포넌트**: 같은 모양을 여러 번 쓰는 부품(카드)은 한 번만 만들어 반복해서 씁니다.
- **링크와 버튼의 차이**: 다른 주소로 이동하는 것은 링크(`<a>`)로 만들어야 새 탭 열기 등이 됩니다.

## 주의할 점 (비고)
- 계약서에는 `code`가 태스크 생성 경로에서는 `null`이 아니라고 하지만, 타입은 안전하게 `null`도 허용했고 그때도 "분석 중"으로 보입니다.
- 날짜는 사용자 브라우저의 시간대 기준으로 표시됩니다(프로젝트 카드와 동일).

# TASK-036. 로그인 페이지

## 상태
완료

## 날짜
2026-11-09

## 작업 요약
빈 로그인 페이지를 **실제 화면**으로 바꿨습니다. 제목, T033의 로그인 양식, "계정이 없나요? 회원가입" 링크가 들어 있습니다.

핵심은 로그인 뒤의 **행선지**입니다. 로그인하지 않고 휴지통 주소로 들어온 사람은 문지기(T037)가 로그인 페이지로 보내면서 "원래 휴지통에 가려던 분"이라는 쪽지를 쥐여 줍니다. 로그인에 성공하면 이 쪽지를 읽고 휴지통으로 안내합니다. 쪽지가 없으면 대시보드로 갑니다. 식당 예약 손님이 대기실에서 이름을 확인받고 원래 안내받던 자리로 가는 것과 같습니다.

## 왜 이렇게 만들었나
- **쪽지를 그대로 믿지 않습니다.** 주소 창에서 누군가 쪽지 내용을 `//나쁜사이트.com` 같은 것으로 바꿔 쓰면 로그인 직후 다른 사이트로 끌려갈 수 있습니다(오픈 리다이렉트 공격). 그래서 `/`로 시작하는 우리 사이트 안의 경로일 때만 따르고, 아니면 대시보드로 보냅니다.
- **교체 이동**: 로그인 후에는 "뒤로 가기"가 로그인 화면으로 돌아오지 않게 합니다.
- **실패하면 머뭅니다.** 비밀번호가 틀리면 서버 문장이 경고 상자에 나오고 로그인 상태는 바뀌지 않습니다.

## 기술 결정
- 행선지는 페이지 이동 상태(`location.state`)로 받습니다. 주소 창에 노출되지 않고, 새로고침하면 사라지는 정도의 가벼운 정보이기 때문입니다.

## 관련 개념
- **오픈 리다이렉트**: 신뢰하는 사이트의 로그인 링크를 이용해 사용자를 가짜 사이트로 보내는 수법입니다.
- **라우터 상태**: 페이지를 옮길 때 함께 건네는 작은 메모입니다.

## 주의할 점 (비고)
- 새 탭에서 로그인 주소를 바로 열면 쪽지가 없으므로 항상 대시보드로 갑니다. 정상 동작입니다.

- 로그인 페이지에서 가입 페이지로 갈 때는 링크만 눌러도 되고, 입력하던 내용은 가져가지 않습니다. 비밀번호가 다른 화면에 남는 일을 피하려는 선택입니다.

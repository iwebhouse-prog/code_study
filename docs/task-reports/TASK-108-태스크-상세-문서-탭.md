# TASK-108. 태스크 상세 화면의 학습 문서 탭

## 상태
완료

## 날짜
2026-11-18

## 작업 요약
태스크 상세 화면의 "학습 문서" 탭이 더 이상 "곧 제공됩니다" 문구가 아니라 실제 `DocumentViewer`를 보여 줍니다. "연습 문제", "질문하기" 탭은 기존 안내 문구 그대로입니다. 두 칸 레이아웃이 들어가야 하므로 본문 최대 너비를 `max-w-3xl`에서 `max-w-6xl`로 넓혔습니다.

탭을 바꾸면 뷰어가 사라지므로 다른 탭에서는 상태 요청(폴링)도 멈춥니다. 이 작업으로 Monaco가 처음으로 실제 앱에서 쓰이게 되어, 빌드에서 Monaco가 **별도 지연 로딩 덩어리**로 나뉘는 것을 확인했습니다.

## 변경 파일
- `frontend/src/pages/TaskDetail.tsx` (문서 탭에 `DocumentViewer`, 너비 확대)
- `frontend/tests/unit/TaskDetailDocument.test.tsx` (새 파일, 시험 3개)

# T112. 코드·설명 스크롤 연동 브라우저 시험

## 상태
**실패 — 수정 필요** (tasks.md 미표시)

## 날짜
2026-11-18

## 작업 요약
코드 패널을 스크롤하면 설명 패널이 그 줄의 4장 항목으로 따라가는지 확인했습니다.

| 확인 항목 | 결과 |
|---|---|
| 코드 위에서 휠 6번 | ❌ Monaco 내부 스크롤 0 그대로, 설명 패널 변화 없음 |
| 페이지 스크롤 | ❌ 코드 위에서는 페이지도 움직이지 않음 (**발견 #3**) |
| 반대 방향(설명 → 코드) | ✅ 4장 "3~7줄" 클릭 → 3~7번째 줄 강조, "21~29줄" → 21~29번째 줄 강조 |

Monaco가 이미 내용보다 훨씬 커서(19만 px) 스크롤할 것이 없으므로 연동이 일어날 수 없습니다. **발견 #2**의 결과입니다.

Playwright MCP(Chromium), 백엔드·Vite·PostgreSQL·Redis·Celery 작업자(`--pool=solo`)·실제 Gemini를 모두 띄운 상태에서 E2E 전체 플로우 시험의 일부로 진행했습니다. 전체 결과는 `E2E-전체-플로우-시험.md`에 있습니다.

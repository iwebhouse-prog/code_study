# TASK-042. 로그아웃 브라우저 테스트

## 상태
완료 (처음에는 보류, T038A 상단 메뉴 추가 후 완료)

## 날짜
2026-11-09

## 작업 요약
이 시험의 목표는 "로그아웃하면 쿠키가 지워지고 로그인 화면으로 이동하는가"입니다. 두 가지 중 **쿠키 삭제는 확인했고**, **로그인 화면으로의 이동은 화면에서 직접 확인하지 못했습니다.** 지금 앱에는 로그아웃 버튼이 있는 상단 메뉴가 아직 없기 때문입니다. 출입문 잠금장치는 달았지만 문손잡이가 아직 없는 상태와 비슷합니다.

확인한 것은 다음과 같습니다.

1. **로그인 응답의 쿠키**: 입장권 쿠키(`access_token`, 15분, 사이트 전체)와 재발급 쿠키(`refresh_token`, 7일, `/api/v1/auth`에서만 전송)가 둘 다 HttpOnly, SameSite=Strict로 심어졌습니다.
2. **로그아웃 응답**: 서버가 **204**로 답하며 두 쿠키를 같은 이름과 경로, `Max-Age=0`(지금 바로 만료)으로 지웠습니다.
3. **로그아웃 뒤**: "나 누구야?" 요청(`/auth/me`)은 401, 쿠키 재발급 요청은 401로 거절되었습니다. 재발급 쿠키도 서버에서 폐기되었다는 뜻입니다.
4. **브라우저에서 로그아웃 뒤 회원 전용 화면에 들어가면** 로그인 화면으로 이동했습니다.

확인하지 못한 것: 버튼을 눌러 로그아웃했을 때 **그 자리에서 바로** 로그인 화면으로 이동하는지. 로그아웃 기능(`useLogout`)은 만들어져 있고 자동 테스트로 검증되어 있지만(T038), 화면에 연결된 곳이 없습니다.

## 왜 이렇게 시험했나
- 버튼이 없어서, 같은 서버 요청을 브라우저 안에서 직접 보내는 방식으로 쿠키 삭제를 확인했습니다. 응답 헤더는 명령줄 도구로도 그대로 확인했습니다.
- 확인하지 못한 부분을 완료로 표시하지 않기 위해 상태를 "보류"로 두었습니다.

## 추가 확인 (T038A 이후, 2026-11-09)
상단 메뉴의 이메일을 눌러 메뉴를 열고 "로그아웃"을 누르자, 서버가 204로 답했고 곧바로 로그인 화면(`/login`)으로 이동했습니다. 상단 메뉴는 사라졌고, 이어서 "나 누구야?" 요청은 401로 거절되었습니다. 처음에 확인하지 못했던 "버튼으로 로그아웃 → 로그인 화면 이동"이 확인되어 완료로 바꿉니다.

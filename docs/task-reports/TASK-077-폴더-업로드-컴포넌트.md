# TASK-077. 폴더 업로드 컴포넌트 (FolderUpload)

## 상태
완료

## 날짜

## 작업 요약
폴더 통째로 올리는 컴포넌트입니다. **이삿짐 센터**를 떠올리면 쉽습니다. 짐(파일)을 상자째 보내되, 쓰레기(`node_modules` 같은 것)는 미리 빼고, 어느 방에 있던 짐인지 라벨(상대 경로)을 붙여 보냅니다.

1. 폴더 선택 입력(`webkitdirectory`)으로 폴더를 고릅니다.
2. 각 파일의 `webkitRelativePath`(예: `my-app/src/App.jsx`)를 그대로 경로로 보관해 폴더 구조가 유지됩니다.
3. FR-017 제외 대상(`.git`, `node_modules`, `__pycache__` 폴더, `.DS_Store` 파일)은 전송 전에 버립니다.
4. 실제로 제외된 이름만 "제외된 폴더: .git, node_modules"처럼 보여 줍니다.

부모에게는 `{ file, path }` 목록(`UploadEntry`)을 전달합니다.

## 기술 결정
- 시험에서는 가짜 파일에 `webkitRelativePath` 값을 직접 넣었습니다. jsdom은 실제 폴더 선택을 흉내 내지 못하기 때문입니다. 실제 브라우저 확인은 T084 이후 브라우저 시험에서 합니다.
- `webkitdirectory`는 React 타입에 없어서 속성 객체로 펼쳐 넣었습니다.

## 관련 개념
- **상대 경로**: 폴더 맨 위를 기준으로 한 파일 위치입니다. 서버가 폴더 구조를 복원하는 데 쓰입니다.
- **제외 규칙(FR-017)**: 학습과 무관하고 용량만 큰 파일을 올리지 않게 하는 규칙입니다.

## 주의할 점 (비고)
- 폴더 선택은 브라우저마다 지원이 조금 다를 수 있습니다(주요 최신 브라우저는 지원).
- 폴더 선택은 끌어다 놓기를 지원하지 않습니다(계약서가 요구하지 않음).
- 제외 후 남은 파일이 0개면 모달에서 "업로드할 파일이 없습니다."가 나옵니다.

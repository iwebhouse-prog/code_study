# TASK-056. 프로젝트 생성 흐름

## 상태
완료

## 날짜
2026-11-10

## 작업 요약
대시보드의 "새 프로젝트" 버튼부터 새 프로젝트의 상세 화면까지, **만들기의 처음부터 끝까지를 한 줄로 이었습니다.** 식당에서 주문(버튼), 주문서 작성(창), 주방 접수(서버), "주문 완료되었습니다" 안내(알림), 테이블로 음식 도착(상세 화면)이 이어지는 것과 같습니다.

1. "새 프로젝트" 버튼 또는 비어 있는 화면의 "첫 프로젝트 만들기"를 누르면 같은 입력 창이 열립니다.
2. 제목을 적고 "만들기"를 누르면 서버에 만들기를 요청합니다.
3. 성공하면 목록을 "오래됨"으로 표시해 다시 받아 오게 하고, "프로젝트가 생성되었습니다." 알림(오른쪽 위, 3초)을 띄운 뒤 새 프로젝트의 상세 화면으로 이동합니다 (CHK085).
4. 실패하면 창이 닫히지 않고 이유가 창 안에 나옵니다. 알림도 이동도 일어나지 않습니다.

## 왜 이렇게 만들었나
- **돌아가면 새 프로젝트가 보이게** 목록 캐시를 무효화합니다. 안 하면 최대 30초간 옛 목록이 보일 수 있습니다.
- 알림을 띄우는 곳은 이동 전이지만, 알림 자리가 메뉴 바와 같은 곳에 있어 화면이 바뀐 뒤에도 남아 3초 뒤 사라집니다.
- 대부분의 부품은 T051~T055에서 이미 만들어 두었고, 이번에는 이를 잇는 함수(`createProject`)가 핵심입니다. 그래서 새 파일은 거의 없습니다.

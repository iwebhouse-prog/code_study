# TASK-107. 생성 중 / 실패 상태 화면

## 상태
완료

## 날짜
2026-11-18

## 작업 요약
학습 문서가 아직 만들어지는 중이거나 실패했을 때 보여 줄 화면입니다(계약의 "Frontend rules").

**생성 중(`pending`/`in_progress`)**: ⏳ "학습 문서 생성 중..." / "AI가 코드를 분석하고 초보자용 설명을 작성하고 있습니다." / 진행 표시줄 / 남은 시간. 남은 시간은 `ceil(초/60)`을 써서 "약 N분 남음", 60초 미만은 "1분 이내"이고, 서버가 값을 주지 않으면 숨깁니다. 영역 전체가 `role="status"`, `aria-live="polite"`라 스크린리더가 상태 변화를 알려 줍니다. 상태가 `completed`로 바뀌면 3초 폴링으로 저절로 문서 화면으로 바뀝니다.

**실패(`failed`)**: 서버가 준 한국어 `error.message`를 알림(`role="alert"`)으로 보여 주고 "다시 만들기" 버튼을 둡니다. 누르면 요청을 보내는 동안 "다시 만드는 중…"으로 잠기고, 성공하면 생성 중 화면으로 돌아가 폴링을 다시 시작합니다. 거절되면(예: 409) 사유를 버튼 위에 보여 주고 버튼은 다시 쓸 수 있습니다. 오류 정보가 없으면 기본 문구를 씁니다. `window.alert`/`confirm`은 쓰지 않았습니다.

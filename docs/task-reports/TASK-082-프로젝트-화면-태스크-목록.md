# TASK-082. 프로젝트 화면의 태스크 목록

## 상태
완료

## 날짜
2026-11-16

## 작업 요약
프로젝트 상세 화면에 있던 "태스크 목록은 곧 제공됩니다." **임시 안내판을 떼고 진짜 목록**을 달았습니다. 가게 문 앞의 "준비 중" 팻말을 떼고 진열대를 놓은 것과 같습니다.

1. 프로젝트의 태스크를 서버에서 받아 와 `task_number` 순서대로 카드(T079)로 보여 줍니다.
2. 받아 오는 동안 "태스크를 불러오는 중입니다…", 실패하면 오류 문구와 "다시 시도" 버튼이 나옵니다.
3. 태스크가 없으면 계약서의 빈 화면을 보여 줍니다: 📝 "아직 태스크가 없습니다", 안내 문장, "첫 태스크 추가" 버튼, 💡 팁.
4. 태스크가 있으면 구역 위에 "태스크 추가" 버튼이 있고, 두 버튼 모두 T081의 만들기 창을 엽니다.

## 기술 결정
- 정렬은 서버가 이미 번호순으로 주지만 작업 지시대로 화면에서도 한 번 더 정렬합니다(비용이 작음).
- 목록 구역의 오류는 프로젝트 정보와 별개로 구역 안에서만 보여, 프로젝트 정보는 계속 볼 수 있습니다.

## 관련 개념
- **빈 상태(empty state)**: 데이터가 없을 때 "무엇을 하면 되는지"를 알려 주는 화면입니다.
- **쿼리 무효화**: "이 데이터는 낡았다"고 표시해 다시 받아 오게 하는 일입니다.

## 주의할 점 (비고)
- 프로젝트 카드의 "완료 n/m 태스크" 숫자는 서버의 `task_count`를 씁니다. 태스크 생성 후 프로젝트를 다시 받아 오므로 갱신됩니다.
- 태스크 삭제 버튼과 알림은 이 작업 범위에 없습니다.

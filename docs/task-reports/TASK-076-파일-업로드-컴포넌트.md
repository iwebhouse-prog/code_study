# TASK-076. 파일 업로드 컴포넌트 (FileUpload)

## 상태
완료

## 날짜
2026-11-16

## 작업 요약
코드 파일을 올리는 **"우편함"** 컴포넌트를 만들었습니다. 우편함 입구에 편지를 던져 넣거나(끌어다 놓기), 우체국 창구에서 직접 접수하는 것(파일 선택 창)처럼 두 가지 방법으로 파일을 고를 수 있습니다.

1. 점선 상자에 파일을 끌어다 놓으면 선택됩니다. 끄는 동안에는 상자가 강조됩니다.
2. 상자를 클릭하거나 키보드로 이동해 Enter를 누르면 파일 선택 창이 열립니다. 여러 파일을 한 번에 고를 수 있습니다.
3. 고른 파일의 이름이 목록으로 나옵니다.

부모 컴포넌트가 선택된 파일을 들고 있고(`files`), 바뀔 때마다 `onFilesChange`로 알려 줍니다. 이 컴포넌트는 검사나 전송을 하지 않습니다. 검사는 T081의 모달이 맡습니다.

## 기술 결정
- 점선 상자를 `<label>`로 만들고 안에 실제 파일 입력(화면에서는 숨김)을 넣었습니다. 그래서 별도 코드 없이 클릭과 키보드 모두 동작하고, 스크린 리더도 읽을 수 있습니다.
- 새로 고르면 기존 선택을 **대체**합니다(일반 파일 선택 창과 같은 동작).

## 관련 개념
- **드래그 앤 드롭**: 브라우저가 파일을 놓는 순간 `drop` 이벤트로 파일 목록을 줍니다. 기본 동작(파일 열기)을 막아야 하므로 `preventDefault`를 호출합니다.
- **접근성**: 마우스 없이도 쓸 수 있어야 하므로 진짜 입력 요소를 사용했습니다.

## 주의할 점 (비고)
- 이 컴포넌트는 확장자나 크기를 검사하지 않습니다. 백엔드가 최종 판단하며, 브라우저 검사는 T081에서 합니다.
- 같은 파일을 연속으로 다시 고르면 브라우저가 변경 이벤트를 주지 않을 수 있습니다(일반적인 파일 입력 동작).

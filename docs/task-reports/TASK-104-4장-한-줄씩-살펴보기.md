## 작업 요약
4장은 코드 조각마다 설명 항목이 하나씩 나오고, **항목을 누르면 왼쪽 코드의 해당 줄이 강조**되도록 이어 주는 챕터입니다.

- 항목 머리글은 버튼입니다: `even_odd.py 1~2줄`(한 줄이면 `4줄`). 마우스와 키보드(Enter, Space) 모두 사용할 수 있습니다.
- 항목 안에는 코드 원문, 하는 일, 문법 풀이, 비유, 다른 예시, 주의할 점이 있습니다. 주의할 점이 빈 문자열이면 숨깁니다.
- `activeIndex`로 지금 연결된 항목을 받아 `aria-pressed`와 테두리로 강조합니다.
- 클릭하면 `onSelectExplanation(index)`로 부모에 알립니다. 코드 강조는 부모(DocumentViewer)가 처리합니다.
- 각 항목에 `data-explanation-index`를 달아 패널이 그 위치로 스크롤할 수 있게 했습니다.

## 기술 결정
- 상태(어느 항목이 활성인지)는 이 컴포넌트가 갖지 않고 부모가 줍니다. 코드 스크롤과도 연결되어야 하기 때문입니다.
- 항목 전체가 아니라 머리글만 버튼으로 하여, 항목 안의 글을 드래그해 복사해도 강조가 바뀌지 않게 했습니다.
- `aria-pressed`를 써서 스크린리더가 선택 상태를 알립니다.

## 관련 개념
- **토글 버튼(`aria-pressed`)**: 눌림 상태를 가진 버튼.
- **상태 끌어올리기**: 여러 부품이 함께 쓰는 값은 공통 부모가 가짐.

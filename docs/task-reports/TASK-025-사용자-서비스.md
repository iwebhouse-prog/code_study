# TASK-025. 사용자 서비스 (회원가입, 로그인, 로그아웃)

## 상태
완료

## 날짜

## 작업 요약
도서관의 회원 창구를 만든 작업입니다. 창구 직원은 세 가지 일을 합니다.

- **회원가입**: 신청서를 확인해 회원증 대장에 올립니다. 이메일은 소문자로 맞춰 적고, 비밀번호는 8자 이상에 문자와 숫자가 모두 있어야 합니다. 비밀번호는 그대로 적지 않고 되돌릴 수 없는 형태로 바꿔 적습니다.
- **로그인**: 이메일과 비밀번호가 맞는지 확인하고 마지막 방문 시각을 적습니다.
- **로그아웃**: 그 기기의 출입 카드만 폐기합니다. 휴대폰에서 나가도 노트북은 그대로입니다.

아직 화면이나 인터넷 주소는 없습니다. 창구 업무 규칙만 완성했고, 손님이 찾아올 문은 T028~T030에서 만듭니다.

## 왜 이렇게 만들었나
- **틀린 이유를 말해 주지 않습니다.** "없는 이메일"과 "틀린 비밀번호"에 똑같이 답합니다. 다르게 답하면 누가 회원인지 알아낼 수 있기 때문입니다. 없는 이메일도 비밀번호 확인을 한 번 거쳐 답하는 시간까지 맞췄습니다.
- **중복 가입은 대장이 막게 했습니다.** 두 사람이 같은 순간 같은 이메일로 신청해도 대장의 "중복 금지" 규칙이 한 명만 받습니다. 직원이 먼저 대장을 살펴보는 방식이면 두 건이 모두 통과할 수 있습니다.
- **오래 걸리는 일은 뒷방에서 합니다.** 비밀번호 확인은 0.2초쯤 걸립니다. 창구에서 하면 그동안 다른 손님이 모두 기다리므로 별도 작업자에게 맡겼습니다.
- **기록에 비밀을 남기지 않습니다.** 업무 기록에는 회원 번호나 `l***@example.com`처럼 가린 이메일만 남깁니다.

## 기술 결정
- 비밀번호 규칙은 문서에 "복잡도 규칙"으로만 적혀 있어, 문서의 예시 비밀번호가 통과하는 기준(8자 이상, 문자와 숫자 포함)으로 정했습니다.

| 3 | 같은 주소로 다시 접속(전체 새로고침) | 바뀐 제목 표시 | 통과 (`GET /projects/{id}` 200) |

## 기술 결정
- **설명은 바꾸지 않았습니다.** 요청 본문에 제목만 보내는 "부분 수정(PATCH)"이 설명을 지우지 않는지 함께 확인하려는 것입니다. 새로고침 뒤 설명이 그대로 남아 있었습니다.
- 수정 뒤 DB의 `updated_at`은 바뀌었지만 `last_activity_at`은 그대로였습니다. data-model.md에 "태스크가 바뀔 때만 갱신"이라고 되어 있어 **설계대로입니다.**

## 관련 개념
- **PATCH**: 바꿀 칸만 보내는 수정 요청입니다. 전체를 덮어쓰는 PUT과 달리 안 보낸 칸은 그대로 둡니다.

## 주의할 점 (비고)

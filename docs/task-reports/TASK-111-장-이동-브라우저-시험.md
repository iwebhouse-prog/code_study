## 작업 요약
장 메뉴로 1~7장을 오가며 **메뉴 강조와 내용 표시**를 확인했습니다.

| 확인 항목 | 결과 |
|---|---|
| 메뉴 강조(`aria-current`) | ✅ 1~7장 모두 누른 장으로 바뀜 |
| 내용이 화면에 옴 | ❌ 4장·7장을 눌러도 페이지·패널이 움직이지 않음 (4장 제목이 화면 아래 2,010px, 7장은 5,669px) |

원인은 **발견 #2**입니다. 설명 패널이 `overflow-y: auto`인데 높이 제한이 없어 7만 px 넘게 늘어났고, 그래서 패널 안 스크롤이 일어나지 않습니다. 그 바탕에는 Monaco 편집기의 높이가 초당 약 1,690px씩 끝없이 커지는 문제가 있습니다.

Playwright MCP(Chromium), 백엔드·Vite·PostgreSQL·Redis·Celery 작업자(`--pool=solo`)·실제 Gemini를 모두 띄운 상태에서 E2E 전체 플로우 시험의 일부로 진행했습니다. 전체 결과는 `E2E-전체-플로우-시험.md`에 있습니다.

## 상태
완료

## 날짜
2026-11-09

## 작업 요약
이름만 있던 빈 회원가입 페이지를 **진짜 화면**으로 바꿨습니다. 가운데 카드에 "회원가입" 제목, 비밀번호 안내 문장, T032의 가입 양식, 그리고 맨 아래에 "이미 계정이 있나요? 로그인" 링크가 있습니다.

가입에 성공하면 서버가 곧바로 로그인 상태로 만들어 줍니다(쿠키를 심어 줍니다). 그래서 화면은 "내 정보"를 저장소에 적고 대시보드로 이동합니다. 새 회원이 놀이공원 입구에서 표를 사면 팔찌까지 채워 주어 바로 입장하는 것과 같습니다. 다시 로그인하라고 시키지 않습니다.

## 왜 이렇게 만들었나
- **가입 후 바로 입장**은 계약서(`auth-api.md`)에 정해진 흐름입니다. 사용자가 같은 정보를 두 번 입력하는 수고를 덜어 줍니다.
- **뒤로 가기 배려**: 이동할 때 "교체" 방식을 써서, 뒤로 가기를 눌러도 이미 끝난 가입 화면으로 돌아오지 않습니다.
- **실패하면 그 자리에 머뭅니다.** 이미 가입된 이메일이면 서버 문장이 경고 상자에 뜨고, 입력한 내용은 그대로 남습니다.
- **기존 화면 시험과 호환**: 이 페이지는 데이터 캐시 도구 없이도 그려지도록 했습니다. 기존 라우트 시험이 캐시 도구 없이 이 페이지를 직접 그리기 때문입니다.

## 변경 파일

## 기술 결정
- 가입 요청은 TanStack Query가 아닌 단순 호출로 처리했습니다. 가입은 한 번만 일어나는 행동이고 저장해 둘 데이터가 아니기 때문입니다.

## 관련 개념
- **상태 저장소(Zustand)**: "지금 누가 로그인했나"를 화면 전체가 같이 보는 칠판입니다.
- **쿠키 자동 로그인**: 서버가 심은 쿠키가 있으면 화면 코드가 토큰을 몰라도 로그인 상태가 유지됩니다.

## 주의할 점 (비고)
- 이미 로그인한 사람이 가입 주소로 들어와도 지금은 그대로 보여 줍니다. 기존 라우트 시험이 로그인된 상태로 이 페이지를 확인하기 때문에 자동 이동은 넣지 않았습니다.

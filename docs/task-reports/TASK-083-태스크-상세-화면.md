# TASK-083. 태스크 상세 화면 뼈대 (TaskDetail)

## 상태
완료

## 날짜
2026-11-16

## 작업 요약
태스크 한 개를 보는 화면의 **뼈대**입니다. 새 집의 골조처럼 방(탭) 세 칸만 먼저 만들어 두고, 가구(학습 문서, 연습 문제, 질문 기능)는 이후 단계에서 들입니다.

1. 주소의 태스크 번호로 서버에서 태스크를 받아 옵니다. 받는 동안 "태스크를 불러오는 중입니다…"가 나옵니다.
2. 머리글은 "Task {번호}. {제목}"이고, 설명이 있으면 아래에 보여 줍니다.
3. "프로젝트로 돌아가기" 링크가 그 태스크의 프로젝트 화면으로 이어 줍니다.
4. 탭: 학습 문서 / 연습 문제 / 질문하기. 처음에는 학습 문서가 선택되고, 내용은 "곧 제공됩니다." 임시 문구입니다.
5. 403, 404면 서버의 오류 문구와 "내 프로젝트로 돌아가기" 링크를 보여 줍니다.

## 기술 결정
- 로딩 중에는 머리글을 두지 않고 안내 문구만 보여 줍니다(프로젝트 상세와 같은 방식).
- 탭은 모든 탭이 버튼이라 Tab과 Enter로 쓸 수 있습니다. 방향키 이동은 필요해지면 추가합니다.

## 관련 개념

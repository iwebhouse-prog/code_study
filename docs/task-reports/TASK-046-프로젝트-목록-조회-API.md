# TASK-046. 프로젝트 목록 조회 API

## 상태
완료

## 날짜
2026-11-10

## 작업 요약
학교 알림판에 **내 반 학생 명단만 최근에 활동한 순서로** 붙여 주는 창구를 만들었습니다. 주소는 `GET /api/v1/projects`입니다.

- 로그인한 사람의 프로젝트만 보여 줍니다. 남의 것과 휴지통에 들어간 것은 빠집니다.
- 가장 최근에 활동한 프로젝트가 맨 위에 옵니다.
- 각 항목은 계약서에 적힌 여덟 가지 정보(번호, 제목, 설명, 만든 때, 고친 때, 마지막 활동, 태스크 수, 완료 태스크 수)만 담습니다. 주인 번호나 휴지통 정보는 절대 내보내지 않습니다.
- 로그인하지 않았으면 401로 돌려보냅니다.

## 왜 이렇게 만들었나
- **창구는 전달만 합니다.** 프로젝트를 고르고 정렬하는 일은 이미 만들어 둔 ProjectService(T044)가 하고, 이번 주소는 결과를 계약서 모양으로 포장만 합니다. 식당으로 치면 홀 직원은 주방에서 나온 접시를 나를 뿐 요리를 하지 않습니다.
- 태스크 수는 아직 태스크가 없어서 늘 0입니다. 그래도 화면 담당이 나중에 모양이 바뀌어 고생하지 않도록 지금부터 칸을 만들어 두었습니다.

## 기술 결정
응답 모양(`ProjectResponse`)은 DB 객체에서 필요한 칸만 꺼내는 방식으로 만들었습니다. 이렇게 하면 나중에 DB에 칸이 늘어도 실수로 밖에 나가지 않습니다.

## 관련 개념
- **응답 모델(response model)**: 손님에게 내보낼 정보를 미리 정한 양식입니다. 양식에 없는 칸은 나가지 않습니다.
- **의존성 주입**: 필요한 도구(로그인 확인, 창구 직원)를 주소 함수가 직접 만들지 않고 받아 쓰는 방식입니다.

## 주의할 점 (비고)
- 지금은 목록 길이에 제한이 없습니다. 프로젝트가 아주 많아지면 나눠 보여 주는 기능이 필요하지만, 계약서에 없어서 넣지 않았습니다.

# TASK-038B. 15분 뒤 로그인이 풀리는 버그 수정

## 상태
완료

## 날짜
2026-11-09

## 작업 요약
로그인하고 15분이 지나면 저절로 로그인 화면으로 돌아가는 버그를 고쳤습니다. 원인은 두 가지였습니다.

**원인 1. 입장권이 사라지면 아무도 재발급을 하지 않았습니다.** 놀이공원 입장권(액세스 쿠키)의 보관 기간을 입장권 유효 기간과 똑같이 15분으로 정해 두었습니다. 그래서 15분이 지나면 브라우저가 입장권을 아예 버렸고, 서버는 "만료된 입장권"이 아니라 "입장권 없음"이라고 답했습니다. 화면은 "만료됨"이라는 말을 들을 때만 7일짜리 쿠폰으로 새 입장권을 받아 오게 되어 있었습니다. 그래서 쿠폰이 있는데도 쓰지 않았습니다. 이제 "입장권 없음"을 들어도 쿠폰으로 한 번 교환을 시도합니다.

**원인 2. 개발 화면에서 쿠폰 교환이 두 번 일어났습니다.** 개발 모드의 React 점검 기능(StrictMode)은 시작 준비를 두 번 합니다. 그 결과 교환 창구가 두 개 생겨 같은 쿠폰을 두 번 내밀었습니다. 서버는 이를 쿠폰 도난으로 판단해(T026) 모든 세션을 끝냈습니다. 이제 창구가 몇 개 생기든 "지금 진행 중인 교환"을 하나로 함께 기다립니다.

## 왜 이렇게 고쳤나
- **서버 대신 화면 쪽을 고쳤습니다.** 서버의 쿠키 보관 기간을 늘리는 방법도 있지만, 기존 서버 테스트 2개를 고쳐야 해서 "테스트 불변" 규칙에 어긋납니다. 화면 쪽 수정은 기존 테스트를 하나도 바꾸지 않습니다.
- **처음 온 손님에게는 조용히 대응합니다.** 한 번도 로그인하지 않은 사람은 쿠폰도 없어서 교환이 실패합니다. 이때는 "세션 종료" 처리를 하지 않고 원래 대답(로그인 필요)만 돌려줍니다.

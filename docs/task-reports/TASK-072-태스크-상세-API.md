# TASK-072. 태스크 상세 API (GET /tasks/{task_id})

## 상태
완료

## 날짜
2026-11-16

## 작업 요약
태스크 한 개의 정보를 돌려주는 API입니다. 도서관에서 **책 한 권의 대출 카드**를 꺼내 보는 것과 같습니다. 카드는 주인만 볼 수 있습니다.

- `200`: 계약의 Task 객체(`code` 요약 포함)
- `403`: 다른 사람의 태스크
- `404`: 없는 태스크, 휴지통에 있는 태스크, 휴지통 프로젝트에 속한 태스크
- `400`: UUID가 아닌 값(필드명 `task_id`)
- `401`: 로그인 안 함

## 기술 결정
- 서비스의 `_load`가 태스크와 프로젝트를 한 번의 `JOIN`으로 읽고, 프로젝트 주인과 휴지통 상태를 함께 확인합니다. 그래서 "남의 것 403 / 없는 것 404" 규칙이 한곳에만 있습니다.
- 권한 오류는 `task_access_denied`로 로그에 남깁니다(FR-110).

## 관련 개념
- **403과 404의 차이**: 403은 "있지만 당신 것이 아님", 404는 "없음"입니다.
- **JOIN**: 두 표를 연결해 한 번에 읽는 SQL입니다.

## 주의할 점 (비고)
- 다른 사람의 태스크에는 `403`을 돌려주므로 그 ID가 존재한다는 사실은 알려집니다. 프로젝트 API와 같은 정책이며 계약에 그렇게 적혀 있습니다.

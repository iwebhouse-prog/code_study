# TASK-081. 태스크 생성 모달 (CreateTaskModal)

## 상태
완료

## 날짜
2026-11-16

## 작업 요약
태스크를 만드는 **접수 창구**입니다. 제목과 설명을 적고, 코드를 올리는 방법을 탭 세 개(파일 업로드 / 폴더 업로드 / 코드 붙여넣기) 중 고릅니다. 앞의 T076~T078 부품을 한 창에 모았습니다.

흐름:
1. 제목(5~255자), 설명(최대 500자), 코드를 입력합니다.
2. "태스크 만들기"를 누르면 먼저 브라우저에서 검사합니다: 허용 확장자(.py .js .ts .jsx .tsx .html .css .java .cpp .c .txt .md, 대소문자 무시), 파일 1~20개, 전체 10MB 이하, 붙여넣기는 코드와 언어 필수. 문구는 백엔드와 같은 한국어입니다.
3. 통과하면 서버로 보냅니다. 서버가 거절하면 `message`와 `suggestion`을 창 안에 보여 주고, 필드 오류(제목 등)는 해당 입력 옆에 보여 줍니다. 창은 닫히지 않습니다.
4. 성공하면 FR-019 확인 단계("업로드 완료")로 바뀌어 올린 파일과 제외된 파일 목록을 보여 주고, "태스크가 생성되었습니다." 알림(3초)을 띄우며, 프로젝트와 태스크 목록을 다시 받아 오게 합니다. "태스크 보기"를 누르면 태스크 화면으로 이동합니다.

## 기술 결정
- 모달이 직접 서비스 호출, 알림, 캐시 무효화를 맡습니다(작업 설명대로). 필요한 것은 `projectId`뿐입니다.
- 창을 닫았다 열면 입력이 초기화되도록 내용 부분을 창 안쪽 컴포넌트로 만들었습니다.
- 캐시는 `['projects']` 전체를 무효화합니다(프로젝트 목록, 상세, 태스크 목록 모두 포함).

## 작업 요약
로그인 후 처음 만나는 **"내 프로젝트" 화면**을 진짜로 만들었습니다. 이전에는 제목만 있는 빈 간판이었습니다. 이제 서버에서 프로젝트 목록을 받아 카드 모음으로 보여 줍니다. 가게 진열대에 비유하면, 물건이 오는 중이면 "불러오는 중", 배송이 실패하면 사유와 "다시 시도" 버튼, 재고가 없으면 친절한 안내판이 나옵니다.

- 불러오는 중: "프로젝트를 불러오는 중입니다…"
- 오류: 서버가 준 메시지와 "다시 시도" 버튼
- 비어 있음(CHK086): 📁, "아직 프로젝트가 없습니다", 안내문, "첫 프로젝트 만들기" 버튼, 예시 문구 (계약서 문구 그대로)
- 프로젝트 있음: 반응형 격자(좁은 화면 1열, 넓어지면 2~3열)와 "새 프로젝트" 버튼

## 왜 이렇게 만들었나
- 데이터 가져오기는 이미 쓰고 있는 TanStack Query에 맡겼습니다. 같은 목록을 다시 열면 캐시를 먼저 보여 주고 뒤에서 새로고침합니다.
- 알림(토스트) 자리는 상단 메뉴 바와 같은 곳(AppLayout)에 두었습니다. 그래야 "만들기" 직후 다른 화면으로 이동해도 알림이 사라지지 않습니다.

## 기술 결정
- 알림은 화면 이동 후에도 남아야 해서 컴포넌트 상태가 아닌 전역 저장소(zustand, 기존 의존성)에 두었습니다.
- 알림 자리는 처음부터 화면에 있게 했습니다. 화면 읽기 도구는 이미 있던 영역의 변화만 읽어 주기 때문입니다.

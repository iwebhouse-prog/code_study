## 상태
완료

## 작업 요약
화면이 서버의 로그인 관련 창구와 대화할 때 쓰는 **전화 교환대**를 만들었습니다. 가입, 로그인, 내 정보 확인, 토큰 갱신, 로그아웃 다섯 가지 전화를 걸 수 있습니다. 화면 코드는 주소나 전송 방식을 몰라도 `login(...)`처럼 이름만 부르면 됩니다.

서버는 사용자 정보를 `skill_level`처럼 밑줄 이름으로 보내고, 화면은 `skillLevel`처럼 낙타 이름을 씁니다. 교환대가 이 말투를 바꿔 주고, 비밀번호 해시나 가입일처럼 화면이 필요 없는 정보는 버립니다.

## 왜 이렇게 만들었나
- **한 곳에서만 주소를 압니다.** 서버 주소가 바뀌어도 이 파일만 고치면 됩니다.
- **토큰은 만지지 않습니다.** 열쇠(토큰)는 서버가 쿠키라는 금고에 넣어 주고, 자바스크립트는 열어 볼 수 없습니다. 그래서 이 서비스는 열쇠에 대해 아무것도 모르고, 이게 가장 안전합니다.
- **시험하기 쉽게 공장 형태로 만들었습니다.** `createAuthService(client)`에 가짜 통신 장치를 끼우면 서버 없이도 시험됩니다. 실제 앱은 `authService`를 씁니다.

- **HTTPOnly 쿠키**: 브라우저가 서버에 자동으로 실어 보내지만 화면 코드는 읽을 수 없는 보관함입니다.

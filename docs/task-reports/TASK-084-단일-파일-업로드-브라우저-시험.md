## 작업 요약
실제 브라우저(Playwright MCP)에서 **파일 하나를 올려 태스크를 만들고, 첫 태스크가 "Task 1"이 되는지** 확인했습니다. 백엔드(T067~T075)와 프론트엔드(T076~T083)를 두 에이전트가 따로 만들었기 때문에, 이번이 두 쪽이 처음으로 실제로 맞물리는 시험입니다. 따로 깎은 두 퍼즐 조각을 처음 맞춰 보는 셈입니다.

| 단계 | 행동 | 기대 | 결과 |
|---|---|---|---|
| 1 | 시험 계정으로 로그인 → 새 프로젝트 "PW 태스크 업로드 시험" | 빈 태스크 안내(📝 "아직 태스크가 없습니다", 팁 문구) | 통과 — 계약서 문구와 같음 |
| 2 | "첫 태스크 추가" → 제목 "인사 함수 만들기" → 파일 영역 클릭 → `hello.py` 선택 | 선택한 파일 목록에 표시 | 통과 |
| 3 | "태스크 만들기" | `POST /projects/{id}/tasks` 201, 업로드 완료 창(FR-019) | 통과 — "Task 1. 인사 함수 만들기", 파일 `hello.py` |
| 4 | 닫기 → 프로젝트 화면 | 카드 "Task 1", 언어 "Python", "완료 0/1 태스크" | 통과 |
| 5 | DB·디스크 확인 | upload_method `file`, 언어 python, 난이도 beginner, 5줄 | 통과 — `storage/uploads/{사용자}/{태스크}/{UUID}.py` |

## 기술 결정
- 실제 파일 입력은 화면에서 숨겨져(`sr-only`) 있어 직접 클릭하면 막힙니다. 사용자가 누르는 **파일 영역(라벨)** 을 눌러 파일 선택 창을 열었습니다. 사용자 동작과 같은 경로입니다.
- Playwright는 프로젝트 폴더 밖의 파일을 읽을 수 없어, 시험 파일을 `.playwright-mcp/upload-e2e/`에 복사해 썼습니다.

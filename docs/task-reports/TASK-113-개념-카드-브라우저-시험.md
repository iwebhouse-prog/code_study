## 상태

## 작업 요약
2장 "미리 알아둘 개념"에 **개념 카드 5개와 비유**가 나오는지 확인했습니다(FR-028/029). 도서관 대출 프로그램(50줄) 문서로 시험했습니다.

| 카드 | 비유 |
|---|---|
| 딕셔너리 | 단어와 뜻이 짝을 이루는 사전이나 전화번호부 |
| 리스트 | 줄 서 있는 사람들이나 마트 영수증의 상품 목록 |
| 함수 | 재료를 넣으면 요리가 나오는 에어프라이어나 믹서기 |
| 불리언 | 전등 스위치의 켜짐과 꺼짐 |
| for 반복문 | 박스 안 사과를 하나씩 꺼내 씻기 |

5개 카드 모두 쉬운 설명·비유·예시·자주 쓰이는 곳 네 칸이 있었습니다.

Playwright MCP(Chromium), 백엔드·Vite·PostgreSQL·Redis·Celery 작업자(`--pool=solo`)·실제 Gemini를 모두 띄운 상태에서 E2E 전체 플로우 시험의 일부로 진행했습니다. 전체 결과는 `E2E-전체-플로우-시험.md`에 있습니다.

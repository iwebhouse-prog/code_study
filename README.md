# AI Code Learning Platform (code_study)

AI가 만든 코드를 프로그래밍을 처음 배우는 사람이 이해할 수 있도록,
업로드한 코드로 7장짜리 초보자용 학습 문서를 만들어 주는 학습 플랫폼입니다.

- 백엔드: Python 3.12, FastAPI, PostgreSQL, SQLAlchemy 2, Celery + Redis, Google Gemini
- 프론트엔드: React, TypeScript, Vite, TanStack Query, Tailwind CSS, Monaco Editor

명세와 설계 문서는 `specs/001-ai-code-learning-platform/`, 개발 기록은
`docs/task-reports/`에 있습니다. 로컬 실행 방법은
`specs/001-ai-code-learning-platform/quickstart.md`를 참고하세요.
